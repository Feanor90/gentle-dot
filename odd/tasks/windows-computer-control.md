- S5 — Shared guards adopted from MarsSall that also apply on macOS: keys and text go only to the app in front when the latest screenshot was taken, refined by the user's choice "Afinarlo (recomendado)" (L2): "Se mantiene el rechazo cuando el cambio lo provocas tú, pero se acepta el app que el propio agente trajo al frente con un clic o open_app ya validados por la blocklist. El blocklist se sigue comprobando antes de cada tecla. Tests RED para ambos casos."; after a native confirmation the previous app must be back in front within a bounded wait or the approved action is dropped; an unknown foreground app refuses the confirmation. Each needs a RED test before adoption and must not weaken any existing check.
- S6 — Working rings (computer-working-rings.md S1–S9) also run on Windows; MarsSall skipped them. Our addition.
- S7 — Windows asks for no OS permission: the Connectors → Computer entry says "Windows asks for no permission for computer control." instead of the macOS permission list.
- S8 — Live acceptance on this machine with an isolated `GENTLE_DOT_DATA_DIR`, against harmless local surfaces only (Notepad, Calculator); no real accounts, connectors, payments, or the user's installed app; kill test apps by PID tree, never `taskkill /IM gentle-dot.exe`. Docs (design.md, install.md, README) describe Windows computer control and its limits (elevated windows unreachable under UIPI).
